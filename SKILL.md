# Sentient-UI

Sentient-UI is an advanced multi-agent swarm orchestration and neural mission control plane.

## Capabilities

- **Multi-Agent Topologies**: Real-time switching between Hierarchical, Mesh, Star, and Ring topologies.
- **GOAP A* Planner**: Automated goal decomposition, world-state bitmask matrix evaluation, and dynamic replanning.
- **Byzantine Quorum**: Fault-tolerant consensus ($3f+1$, Raft, Paxos, Gossip).
- **314+ MCP Tools**: Comprehensive directory of Model Context Protocol tools.
- **Cognitive Memory Loop**: $\text{RETRIEVE} \rightarrow \text{JUDGE} \rightarrow \text{DISTILL} \rightarrow \text{CONSOLIDATE}$.
- **3-Tier Model Routing**: Deterministic codemods, reflex triage, and frontier reasoning.

## Getting Started

```bash
# 1. Install dependencies
npm install

# 2. Launch frontend
npm run dev

# 3. Launch telemetry server
npm run server
```
