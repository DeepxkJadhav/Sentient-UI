## ? Core Features

- **Multi-LLM Routing Engine:** Automatically routes requests across **Anthropic Claude 3.5 Sonnet, OpenAI GPT-4o/4o-Mini, Google Gemini 1.5 Pro, and Local Ollama** to optimize token costs, response speed, and reasoning depth.
- **Collaborative Subagents:**
  - `Sentient-Coder`: Algorithm design, clean code synthesis, refactoring.
  - `Sentient-Security`: Static vulnerability analysis, OWASP compliance auditing.
  - `Sentient-DevOps`: Docker containerization, Kubernetes manifest generation.
- **Persistent Vector Memory:** High-dimensional semantic storage for multi-turn task persistence.
- **Studio Dashboard:** Real-time web studio with execution graphs and latency metrics.

## ?? Quickstart

```bash
# 1. Install dependencies
pip install -r backend/requirements.txt

# 2. Run Sentient-UI Server
uvicorn backend.app.main:app --port 8001 --reload
```

Open **`http://localhost:8001`** in your browser to access the Sentient-UI Agent Studio!
